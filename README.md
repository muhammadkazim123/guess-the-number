# Number Theory

A classic arcade-inspired number guessing game
created for World Coding Day 2026.

## Technologies
- Python
- Flask
- HTML
- CSS

## How to play
1. Start the application.
2. Enter a number between 1 and 100.
3. Follow the higher/lower hints.
4. Find the secret number within seven attempts.
5. Start a new round and play again.

## Running the project

Install dependencies:

pip install -r requirements.txt

Start the application:

python app.py

Open http://127.0.0.1:5000
in your browser.

## Features
- Random number generation
- Seven attempts per round
- Higher and lower hints
- Input validation
- Win and lose conditions
- Restart functionality
- Retro arcade interface
